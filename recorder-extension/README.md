# Zustand Desktop Recorder

Der Desktop Recorder nimmt externe und interne Web-Apps direkt im echten Browser-Tab auf. Es gibt keine Screenshot-Fernsteuerung und keinen lokalen Node-Prozess.

## Pilot-Installation

1. `recorder-extension.zip` laden und entpacken.
2. In Chrome oder Edge die Erweiterungsseite öffnen und **Entwicklermodus** aktivieren.
3. **Entpackte Erweiterung laden** und den Ordner `recorder-extension` wählen.
4. `https://digitalisierungsplanung.de/state.html` neu laden. Im Tab **App Recorder · Input** steht dann `Recorder bereit`.

Für die öffentliche Produktversion wird derselbe Extension-Code als signiertes Browser-Store-Paket verteilt; am State-/Recording-Vertrag ändert sich dadurch nichts.

Passwortfelder werden aufgezeichnet, aber ihr Wert wird nie gespeichert. Öffentliche Seiten und Intranet-Hosts funktionieren über denselben lokalen Browser-Kontext des Benutzers.
